# 🐎 ASHWA

### Ride Smarter. Train Better. Grow Together.

**ASHWA** is an AI-powered horse-riding training mobile application currently under active development, built with Flutter and powered by a FastAPI backend.

The vision is to create a modern riding companion that brings horse-riding training, learning resources, horse management, and intelligent training assistance together in one place.

> 🚧 **STATUS: WORK IN PROGRESS**
>
> ASHWA is actively being developed. Features, UI, and functionality are subject to change as the project evolves.

---

## ✨ About

ASHWA aims to support riders throughout their training journey through a modern mobile experience, rider profile management, horse information, and riding-session tracking.

The project is being built step by step, with a focus on creating a strong foundation for a future AI-powered horse-riding training platform.

## 🚀 Features

- 🔐 User registration and login
- 👤 Rider profile management
- 🖼️ Profile image upload and persistence
- 🐴 Horse information management
- 🏇 Riding-session tracking
- 📜 Ride history
- 🎨 Theme-aware user interface
- 📚 Learning resources and training videos
- 🤖 Future AI-powered riding assistance

*Some features are still under development or planned for future releases and may not be fully functional.*

## 🛠️ Tech Stack

| Technology | Purpose |

| Flutter | Cross-platform mobile application |
